이타카 문명 시뮬레이터

노란 칸에 입력

불가사의와 보너스 적용 레벨을 선택하면 페넬로페의 난로의 드라크마 생산 보너스와 추가 일반 일꾼·어부를 표시합니다. 이타카에는 행복도나 기초 자원 생산 보너스가 없습니다. 드라크마 시간당 생산량은 인게임 표시값을 직접 입력합니다.
기본 운영 시간(h)은 개별 시간이 비어 있는 항목에 적용됩니다. 상세 설정에서는 행 운영 시간 → 항목 운영 시간 → 기본 운영 시간 순으로 적용하며, 0시간은 입력한 값으로 사용합니다.

최대 도달(자원 기준)은 올리브·포도·문어·매스틱과 중간 자원·상품의 보유량, 운영 시간 동안의 예상 생산·소비를 반영해 기초 자원으로 충당 가능한 불가사의 레벨을 계산합니다. 부족한 상품과 중간 자원은 선택한 주기의 Lv6 소비 비율로 역산합니다. 개별 상품의 생산 시간 충족 여부는 판정하지 않습니다.

목표 달성 현황

목표 달성 현황은 현재 레벨 다음부터 목표 레벨까지의 구간 필요량에, 부족한 상품을 생산하는 데 필요한 중간 자원을 더해 계산합니다. 현재 보유량과 예상 생산량을 반영해 잔여/부족을 표시합니다.
소요 시간은 현재 보유량을 고려한 부족분을 해당 항목의 건물 구성으로 생산하는 데 걸리는 시간입니다. 재료 확보 시간과 생산 순서는 포함하지 않으며, 자원까지 충당 가능한지는 목표 레벨 생산력 비교에서 확인합니다. 목표 레벨은 현재 레벨보다 높게 유지하며, 최고 Lv50에서는 50으로 표시합니다.

수면 대비 자원 확보

수면 대비 자원 확보는 수면까지 남은 시간(h)과 수면 중 생산 주기·횟수를 기준으로 중간 자원·상품 생산에 필요한 재료를 계산합니다. 보유량과 취침 전 생산·소비를 반영해 자원별 필요 생산력과 생산력 차이를 표시합니다.
취침 전 생산량은 수면까지 남은 시간을 모든 생산 항목에 공통 적용하며, 시간이 비어 있으면 기본 운영 시간을 사용합니다. 선택한 주기가 없는 레벨은 가능한 최장 주기를 적용합니다. 수면 중 기초 자원 생산량은 취침 전 확보량에 포함하지 않습니다.

목표 레벨 생산력 비교

목표 레벨 생산력 비교는 현재 생산력에서 필요 생산력을 빼서 생산력 차이를 계산합니다. 상품 부족분뿐 아니라 생산에 필요한 중간 자원·기초 자원과 현재 보유량까지 반영합니다.
생산력은 각 생산 항목의 Lv6·30분 생산을 100으로 환산한 지수입니다. 기초 자원은 Lv6·8시간 생산량의 30분 환산값을 기준으로 합니다. 현재 생산력은 건물 구성과 적용 운영 시간을 반영하며, 상세 구성은 행별 완료 생산량과 운영 시간을 반영합니다. 필요 생산력은 보유량을 차감한 부족분을 운영 시간 안에 생산하기 위해 필요한 값입니다.
상품 생산의 자원 소비 주기는 상품·중간 자원을 생산하는 데 필요한 재료량을 역산할 때 사용하는 Lv6 소비 비율의 기준입니다. 생산 계산기의 실제 생산 주기는 바꾸지 않습니다.

생산력 환산표

생산력 환산표는 건물 1채의 레벨·생산 주기별 시간당 생산량을 각 항목의 Lv6·30분 기준과 비교한 값입니다. 기초 자원은 8시간 생산량을 시간당 생산량으로 환산합니다. 상세 설정에서 여러 주기를 선택하면 선택한 주기를 모두 표시합니다.

도시 현황

영토 현황

일반 영토와 해안 영토의 건물 면적을 각각 합산합니다. 불가사의 레벨별 확장과 시작 영토의 구분을 확인할 때까지 전체 면적·잔여 면적 계산은 보류합니다. 보석 해금 수는 저장됩니다.

일꾼 현황 · 주택

건물 구성

주택은 일반 일꾼·어부를 구분합니다. 생산 건물 수는 생산 계산기의 중간 자원·상품 설정을 합산하여 기본 연동하고, 직접 입력하면 입력값을 우선 사용합니다.

드라크마 현황

현재 보유량운영 시간(h)시간당 생산량예상 보유량

시간당 생산량은 인게임에 표시된 값을 입력합니다. 운영 시간을 비우면 생산 계산기의 기본 운영 시간을 사용합니다.
예상 보유량 = 현재 보유량 + 시간당 생산량 × 운영 시간

건물 건설 비용

누적 건설 비용

현재 레벨 0은 새 건물 건설입니다. 건설 수는 비용 계산에만 사용하며 현재 건물 수에 반영하지 않습니다. 호화 건물은 보석 비용을 구분합니다.

연구

필요 드라크마

연구를 클릭해 현재 완료 또는 목표로 선택합니다. 복수 선택할 수 있으며 선행 연구를 자동 포함합니다. 연구명은 데이터의 영문명을 옮긴 표기로, 게임의 한국어 명칭과 다를 수 있습니다.

제작자 Mule

상세 설정

서로 다른 레벨·건물 수·생산 주기를 입력합니다. 상세 설정을 끄면 기본 항목 설정을 사용하며 상세 구성은 유지됩니다.

입력값 초기화

기본값은 기초·중간 자원 건물 Lv1, 상품 건물 Lv4, 모든 생산 건물 0채, 운영 시간·보유량·불가사의 현재 레벨은 0, 목표 레벨은 1입니다.
